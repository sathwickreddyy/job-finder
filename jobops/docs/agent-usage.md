# Using your existing assistant

The current app supplies complete prompts and stores results. The earlier task/mission/API workflow has been retired. Follow the [first-opening walkthrough](../README.md#your-first-opening-step-by-step).

1. **Find openings:** copy the complete prompt into a conversation that already knows your work. Review its India-focused shortlist; require real source links and full descriptions.
2. **Save a description:** copy one role into JobOps, including its original listing. Recheck that it is open before acting.
3. **Review a resume:** select that role and the actual uploaded PDF on Resume prompt. Attach the file in your assistant and review each suggested change. Upload the agreed revision separately, with change notes and any sourced assessment.
4. **Apply or ask for a referral:** choose the relevant prompt from the saved opening. Let your assistant help with the form or message, then confirm before the external final action. If computer use is unavailable, use the returned checklist or message manually.
5. **Record the outcome:** save only an actual submission or sent message as sent, with the exact file and date. Otherwise leave it planned. A referral message is tracked separately from an application.
6. **Check replies:** refresh a connected Inbox on demand and read Needs attention. You can link a message to an existing record without changing its stage.

You can edit every complete prompt and add preferences supplied from another conversation. JobOps does not read ChatGPT or Claude memory automatically and never requires an AI API key.
