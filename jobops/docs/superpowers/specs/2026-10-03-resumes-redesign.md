# Resume redesign

Approved gallery selections: list A (file rows), file details B (application history first), upload A (focused drawer).

Each row shows an exact PDF version, filename, default status and its own company/role usage. Search covers file, company and role; a used-files filter keeps submitted applications separate from preparing/outreach records. The default file never replaces the file attached to an existing application.

Details use a version rail and open on Applications. PDF preview and Changes and assessments remain available, preserving source-labelled assessments, change editing, extraction retry, download, prompts and archive/default settings. Existing version/tab URLs keep working.

Upload opens only when requested. Support a new resume or a revised version, native PDF selection/drop, a version name, optional changes and default setting, real saving/error feedback. Preserve originals and use existing server actions; no schema changes, external submissions or invented activity/ATS scores.

Use shared Material 3 tokens and responsive neutral surfaces. Keep the gallery for reference. Verify using the marked jobops_e2e database, port 3211 and data/e2e-uploads; never mutate personal records during testing.
